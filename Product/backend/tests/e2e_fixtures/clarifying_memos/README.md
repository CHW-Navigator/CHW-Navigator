# Synthetic NOG clarifying memos

These fictional documents are test instruments, not clinical policy or
operational authority.  They model the narrow written clarifications that a
clinical or operations team might provide during implementation.

A fixture may use a memo only when it names the memo ID in `clarifying_memos`.
The memo is an auditable sidecar, not hidden training input.  In particular,
source-blocked fixtures deliberately cite no memo: a clarification must not
invent an omitted threshold, owner, timing, or resolution for a contradictory
manual.
