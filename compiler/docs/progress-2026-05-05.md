## Temporary gen7 workaround

The `gen7` artifact bridge was developed as a short-term compatibility adapter for:

- `Product/backend/output/gen7_test_run`

That work was intentionally split away from the main compiler branch and parked on:

- `codex/gen7-temp-bridge`

Why it stays separate:

- it accepts looser temporary syntax such as infix `AND` / `OR` / `NOT` / `==`
- it normalizes non-canonical identifiers from a one-off artifact format
- it should not weaken the long-term compiler contracts

Generated gen7 outputs such as translated IR, Mermaid, and PNG flowcharts are therefore not part of the main compiler branch unless explicitly promoted later.
